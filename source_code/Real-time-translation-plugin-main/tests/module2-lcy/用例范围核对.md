# 用例范围核对

核对来源：tests/module1（38条）、tests/module1-lcy（24条）、tests/module2-ai（24条），共86条既有课程用例。

新增24条全部执行Azure适配器，不复制已有用例或改号计数。

| 新增范围 | 既有范围及区别 |
|---|---|
| SDK配置与启动 001–006 | 既有配置测试检查网关环境变量；新增检查Azure SDK工厂选路、实际参数传递及启动Promise |
| 音频输入与时间轴 007–011 | 既有音频测试检查协议编解码和降采样；新增检查SDK接收的子数组所有权、停止后写入和100ns时间转换 |
| 识别结果转换 012–016 | 既有字幕测试检查共享合并器/DOM，Gummy测试检查其事件协议；新增检查Azure ResultReason、语言回退、翻译Map和修订分配 |
| 结束与取消 017–024 | 既有客户端错误测试检查RealtimeClient；新增检查Azure SDK资源释放、迟到回调及CancellationReason/ErrorCode分类 |

产品已有Fake provider的终止契约测试可作为需求依据；它不执行AzureSession，不能验证Azure实现。产品audio-timeline测试是重连偏移的纯函数测试，新增010/011则经Azure SDK回调验证钳制与tick换算。
